# Documentation Technique MaxOS

## 1. Introduction

Bienvenue dans la documentation technique de MaxOS, un système d'exploitation en cours de développement, conçu pour fonctionner sur l'architecture x86. MaxOS est actuellement à un stade de "prototype bare metal" (score estimé : 35/100), se concentrant sur les fonctionnalités fondamentales nécessaires au démarrage d'un système d'exploitation.

**Objectif principal :** Fournir une plateforme stable et éducative pour l'apprentissage et le développement de systèmes d'exploitation, en partant des bases du démarrage et de l'interaction matérielle minimale.

**Statut actuel :** MaxOS est capable de démarrer sur une machine x86 (réelle ou virtuelle) et d'afficher du texte sur l'écran via le mode texte VGA 80x25. Cela représente la première étape cruciale vers un système d'exploitation fonctionnel.
