# Documentation Technique MaxOS

Bienvenue dans la documentation technique de MaxOS, un système d'exploitation bare-metal en phase de prototype avancé. MaxOS est conçu pour l'architecture x86 et vise à fournir une plateforme éducative et expérimentale pour l'apprentissage du développement de systèmes d'exploitation. Actuellement, il démontre les capacités fondamentales de démarrage et d'affichage
