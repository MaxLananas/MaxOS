# Documentation Technique MaxOS

## Introduction

Bienvenue dans la documentation technique de MaxOS. MaxOS est un système d'exploitation bare-metal en phase de prototype avancé, conçu pour l'architecture x86. Ce projet vise à construire un OS à partir de zéro, offrant une compréhension approfondie des mécanismes fondamentques d'un système d'exploitation. Actuellement, MaxOS est capable de démarrer sur une machine x86 et d'afficher du texte via le mode VGA 80x25.

Ce document sert de guide complet pour les développeurs souhaitant comprendre, compiler, tester et contribuer au développement de MaxOS.
