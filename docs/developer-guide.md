# Documentation Technique MaxOS

## Introduction

MaxOS est un système d'exploitation bare-metal en cours de développement, conçu pour fonctionner directement sur le matériel x86 sans dépendance à un système d'exploitation hôte. Actuellement au stade de prototype "bare metal" (score 35/100), MaxOS vise à fournir une plateforme robuste et éducative
